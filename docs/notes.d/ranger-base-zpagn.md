## A corpus expression, in three pins, with one spelling of the hole

Three tree censuses filtered their corpus to `.sh` or a basename of
`Makefile`:

    internal/treepins/patternkill_qa_test.go      (the pattern-kill ruling)
    internal/treepins/scratchrex_qa_test.go       (a rex call that names no server)
    internal/treepins/selftestforkarm_qa_test.go  (an assertion arm's forked matcher)

This repository keeps three **extensionless** bash programs under `scripts/` —
the landing gate, the post-landing judge and the wall check — so each census
read 64 of the 67 tracked programs there and none of them read those three.
The subjects make the gap concrete: the first is the ruling every crew seat
enforces with a PATH shim, the second is the fix direction of the day a server
call that addressed no server ended eight live seats in three seconds, and the
third is a pin whose own exemption table is EMPTY with the comment "the shape
is now enforced everywhere in scripts/" — a claim a corpus that could not see
the biggest `--self-test` in the tree had no standing to make.

### The floor goes on what the shebang decided, not on the count

Each sweep already floored the number of files it read (`scanned < 30`), and
that floor was green through the whole defect: 38 of 41 is not "almost
nothing". What moves to **zero** when a corpus narrows back to an extension

floored — at one rather than at the three the tree holds, because renaming any
of them to `.sh` is ordinary work and must not red a pin about pattern kills.

For the third census the widening also had to be worth something: a real

## An argument swap that landed on the line nobody reads

`scripts/posse-wall-check`'s `evidence()` returns the FIRST non-marker
`file.go:NN:` line of a member's output and truncates it to 300 characters;
the launcher puts that one line on a P1 bead. A previous close moved three
seat accounts to the front of their lines so the bead gets the account rather
than a fixture path. For `wallclaudeprojects_qa_test.go` the swap landed on an
`Errorf` inside `if len(afterOwn) <= len(beforeOwn)`, and the unconditional
`Logf` above it is the line that always renders — so the fix was applied to the
one message of the pair the bead never carries.

MEASURED 2026-11-23 by running the member and slicing its output in runes the
way `evidence()` does (`go test -count=1 -v -run
TestLiveWallClaudeProjectsRefusesPeerPlants ./internal/posse`, 1.29s, PASS):

    before   252 characters rendered, the account's verb at 132 of the 300,
             61 of those 132 the interpolated binary path
    after    190 characters rendered, the verb at 70, and no path can move it

What the swap buys is not headroom, it is independence: the account's place is
a prefix plus a literal the file controls.

## And the swaps are held per FILE, because nothing held them at all

All three rows of that close reverted to their pre-fix blobs left every arm of
`internal/treepins/wallmemberaccount_qa_test.go` GREEN, `make treepins-check`
green, the three members green and `make fmt-check` green. Arm 6 counts an
interpolated verb as ZERO by design, so argument ORDER is outside what it can
see, and arm 2's floor only asked that SOME message defer its prose to a second
line — the deferred count went 7 to 5 and nothing read it. Three beads' work
could be undone by one editor who found a sentence awkward.

Arm 2 now carries `wmaDeferredRoster`: one row per member file that renders an
account in front of a newline, with how many of its messages do (7 messages in
3 files). Keyed on the **file and a count**, which is the only key stable under
both of the ways this record moves — a line number goes stale at the next
landing that moves one (twice already, which is why the old floor stopped
naming lines), and a copy of the message text would red on a reword, which is
ordinary work. A new message of this shape lands without touching the table; an
unswap cannot. Each of the four unswaps reds, naming its file and its live
entries.

## A roster the count was the size of, and nothing resolved the names

The wall check's `nonmember_ceiling` gives the member count its floor, and a
previous bead gave the number a roster to be the size of. It held it to "at
least `ceiling` backticked `Test…` names somewhere in the roster SECTION",
which is not the claim "the roster names `ceiling` non-members". MEASURED
2026-11-23, each on top of a 3 → 4 bump of the body AND the record, alone:

    a 4th name added as PROSE, in a sentence naming it to EXCLUDE it   GREEN
    a 4th BULLET naming a test that is nowhere in the tree             GREEN

So a bump could pay for itself with a name the sentence was excluding, or with
a test that does not exist. The arm now reads the bullet list and resolves
every name in it, by three questions that are each the record's own sentence
asked of the tree: the name must be DECLARED in the package the check runs,
SELECTED by the check's own `member_pattern` (read and never retyped), and must
reach NONE of the nest gate's spellings — because the gate is the membership
marker's only emitter, so a rostered test that reaches it prints the marker and
IS a member. The reach is `wallnestgate_qa_test.go`'s, at its measured depth;
two spellings of "does this pin reach the gate" would be two answers about one
member set. Six mutants, six reds, each naming its reason; the record says in
its own roster paragraph that the bullets are what is read.

## Two pins over one claim, twice

A close landed a second copy of two pins that were already on main 25 minutes
earlier in the same lineage. MEASURED 2026-11-23, each mutant alone: the hand
prompt's stamp write deleted reds BOTH `cmd/posse` pins, and the governance
predicate's own exclusion arms deleted (14 lines) reds BOTH predicate pins with
the four older composite pins green beside them.

Neither copy was wrong and the suite cost was 9s. What makes it a finding is
that two pins stood over one claim with neither naming the other: the next bead
to edit either had no way to know the other existed, and a reader who found
both could not tell which was live. So there is one of each, and each carries
the arms its retired twin had that it did not — the fixture asserted STAMPLESS
before the verb runs and the whole record checked for preserved fields; an
excluded seat raising NOTHING rather than a blank row, and a record with no
launch clock to AGE as its own abstention.

Which copy survived was decided by what the tree already pointed at and by what
each cost. In `cmd/posse` two live readers name the survivor. In
`internal/posse` the retired pair read a WRITTEN package var, which forces them
serial, and sat in an untagged file — so one claim about a pure predicate ran
three times per `make test`, once per arm. Where a retired pin had a reader,
the file it left behind carries a comment saying where the claim is pinned and
why it is not pinned there.
